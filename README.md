Ai chatbot
//What This Project Is
This is a simple web-based chatbot that uses Google's Gemini AI to give smart replies to user messages.

//What Each File Does
index.html

This is the main structure of the chatbot (HTML code).

It includes the heading, message area, input field, and send button.

styles.css

This controls how the chatbot looks (colors, fonts, layout, etc).

It has a dark theme, responsive design, and smooth scroll.

script.js

This file handles the main logic (JavaScript code).

When the user sends a message:

It calls the Gemini API with the message.

Receives a reply.

Shows the reply in the chat window.

It also shows profile pictures for both the user and the bot.

user.jpg

This is the profile image shown for the user's messages.

bot.jpg

This is the profile image shown for the bot's messages.

 //How It Works (Step by Step)
You type a message in the input box.

You click "Send" or press Enter.

Your message is sent to Gemini AI using the API.

Gemini sends back a reply.

The bot’s reply appears on the screen with its profile picture.
